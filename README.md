# Crypto-Horizon
Welcome to **Crypto Horizon**, an AI and Machine Learning repository designed to forecast **Bitcoin (BTC/USD)** price movements and directional velocity. This project is built for quantitative analysts, data scientists, and algorithmic trading enthusiasts who want to look past basic chart pattern. Instead of analyzing Bitcoin in a vacuum, Crypto Horizon exploits the **deep structural market correlations and chart alignment of Binance Coin (BNB/USD)**. By analyzing high-density capital flows and structural liquidity linkages across a comprehensive of a **decade dataset (2015-2025)** sourced from Kaggle, this engine decodes the hidden lead-lag dynamic that drive macro crypto cycles.
